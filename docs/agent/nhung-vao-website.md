# Nhúng Agent vào trang web

Đưa một Agent lên trang web nội bộ hoặc cổng thông tin bằng iframe.

---

1. Trên trang **Agent**, nhấn vào Agent cần nhúng để mở trình soạn thảo.
2. Nhấn **Quản lý** > **Nhúng vào trang web** ở góc trên bên phải.
3. Chọn các tùy chọn:
    - **Kiểu nhúng**: khung chat toàn màn hình (iframe truyền thống) hoặc *widget nổi* ở góc trang.
    - **Giao diện**: sáng hoặc tối (với kiểu toàn màn hình).
    - **Ẩn avatar**: ẩn/hiện ảnh đại diện.
    - **Bật phản hồi dạng luồng**: hiển thị câu trả lời dần theo thời gian thực (với widget).
    - **Ngôn ngữ**: ngôn ngữ giao diện của khung chat.
4. Sao chép mã iframe được sinh ra và dán vào trang web của bạn.
5. Nhấn **Chat trong tab mới** để xem thử Agent với cấu hình vừa chọn trước khi nhúng.

!!! note "Khóa API"
    Nhúng cần một khóa API. Nếu hộp thoại báo thiếu khóa, hãy tạo khóa tại **Cài đặt người dùng** > **API** hoặc liên hệ quản trị viên. Không chia sẻ mã nhúng chứa khóa API ra ngoài tổ chức.
