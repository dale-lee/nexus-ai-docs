# Nhúng Agent vào trang web

Đưa một Agent lên trang web nội bộ hoặc cổng thông tin bằng iframe.

---

1. Trên trang **Agent**, nhấn vào Agent cần nhúng để mở trình soạn thảo.
2. Nhấn **Quản lý** > **Nhúng vào trang web** ở góc trên bên phải.
3. Chọn các tùy chọn:
    - **Loại nhúng**: **Trò chuyện toàn màn hình** (iframe truyền thống) hoặc **Widget nổi** (kiểu Intercom, nằm ở góc trang).
    - **Giao diện**: **Sáng** hoặc **Tối** (với kiểu toàn màn hình).
    - **Ẩn ảnh đại diện**: ẩn/hiện ảnh đại diện.
    - **Ngôn ngữ**: ngôn ngữ giao diện của khung chat.
    - Thẻ **Widget Customization**: tùy chỉnh thêm cho widget nổi.
4. Sao chép **Mã nhúng** (iframe) và dán vào trang web của bạn.
5. Nhấn **Chat trong tab mới** để xem thử Agent với cấu hình vừa chọn trước khi nhúng.

Hộp thoại nhúng giống với hộp thoại nhúng trợ lý hỏi đáp:

![Hộp thoại nhúng vào trang web](../img/hoi-dap/04-nhung.jpg)

!!! note "Khóa API"
    Nhúng cần một khóa API. Nếu hộp thoại báo thiếu khóa, hãy tạo khóa tại **Cài đặt người dùng** > **API** hoặc liên hệ quản trị viên. Không chia sẻ mã nhúng ra ngoài tổ chức.
